# Пропускная система

Контроль въезда и выезда автомобилей: отдельные страницы отделов, экран охраны и панель администратора.

## Как выложить на GitHub и в продакшн

1. На [github.com/new](https://github.com/new) создайте **приватный** репозиторий (например `checkpoint`).
2. Загрузите файлы этого проекта в репозиторий (через «uploading an existing file» или GitHub Desktop).
3. Откройте [vercel.com](https://vercel.com), войдите через GitHub и нажмите **Add New Project**.
4. Выберите этот репозиторий. Framework: Vite / Other. Команда сборки: `npm run build`.
5. Подключите базу Postgres (Neon из кабинета Vercel или [neon.tech](https://neon.tech)) и добавьте переменную **`DATABASE_URL`**.
6. Deploy. Каждый push в `main` будет выпускать новую версию.

## Что умеет система

- Отдел оформляет въезд (модель и госномер).
- Охрана разрешает въезд и выезд.
- Отчёт охраны по календарной дате или промежутку дат.
- Администратор закрепляет адреса отделов и правит любые заявки.

Данные общие для всех рабочих мест (хранятся в Postgres).
